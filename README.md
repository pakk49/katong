## ✨ สิ่งที่อัปเดตใหม่ในเวอร์ชันล่าสุด

1. **🔤 ชื่อตัวละครและข้อความแชทคมชัดระดับ HD (1280×720 Crisp Typography):**
   - อัปเกรดความละเอียดหน้าจอเป็น **1280×720 HD** โดยคงความคลาสสิกของภาพพิกเซลอาร์ต 16-Bit และแสดงชื่อบนหัวตัวละคร กล่องข้อความแชท และป้ายสถานที่ด้วยฟอนต์ความละเอียดสูงพร้อมขอบดำอ่านง่ายชัดเจนทั้งบนมือถือและคอมพิวเตอร์
2. **🔗 เชื่อมต่อกับแฟนเสถียรขึ้น 100% (Auto-Handshake & Self-Healing Sync):**
   - รองรับรหัสห้องทั้งภาษาอังกฤษ ตัวเลข และภาษาไทย (แปลงเป็นรหัสห้องตรงกันอัตโนมัติ)
   - เพิ่มระบบส่งคำขอเข้าห้องซ้ำอัตโนมัติ (Auto-Retry Handshake) + Full-State Sync ทุก 1 วินาที + STUN/TURN Servers เพื่อให้เชื่อมต่อข้ามเครือข่าย (มือถือ 4G/5G ↔ Wi-Fi) แล้วเห็นตัวละครของกันและกันทันที
   - เพิ่มปุ่ม **💕 วาร์ปไปหาแฟน** และ **ลูกศรหัวใจบอกทิศทางแฟน** เมื่อเดินอยู่คนละโซนในแผนที่ใหญ่
3. **🎥 กล้องล็อคติดตัวละครตัวเอง 100% + แผนที่ใหญ่ 6400 × 4800 (8 โซน):**
   - ซุ้มประตูใหญ่ทางเข้า, สวนไผ่หิ่งห้อย, เขตวัดไทย, ตลาดของกิน, ตลาดโคมไฟ, ลานกลางเทศกาลและเวที, ท่าน้ำ 5 ท่า และเกาะพระจันทร์เต็มดวง
