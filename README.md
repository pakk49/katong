# ลอยกระทงด้วยกัน (Real-time Multiplayer • GitHub Pages 100%)

เว็บเกมลอยกระทงออนไลน์เล่นกับแฟนแบบ Real-time สไตล์ 2D Pixel Art พร้อมระบบแต่งตัวละคร เลือกเพศ ทรงผม สีผม และชุดไทยหลากหลายแบบ

## วิธีเอาขึ้น GitHub Pages

1. แตกไฟล์ ZIP นี้ แล้วอัปโหลดไฟล์ทั้งหมดขึ้น GitHub Repository ของคุณ (`pakk49/katong`)
2. เข้าไปที่หน้า Repository บน GitHub -> กดแท็บ **Settings** -> เลือกเมนู **Pages** ด้านซ้าย
3. ตรง **Build and deployment** เลือก Source เป็น **Deploy from a branch** -> เลือก Branch `main` และโฟลเดอร์ `/ (root)` หรือ `/docs` -> กด **Save**
4. เปิดลิงก์เว็บของคุณ ตั้งรหัสห้อง แล้วกดปุ่ม **"🔗 ชวนแฟน"** ส่งให้แฟนเข้ามาเดินเล่นและลอยกระทงด้วยกันได้เลย!
